# PubAd Panic! — UGC NET Public Administration Quiz Arena

A mobile-friendly, static quiz website built from the uploaded **2026 JUNE** question bank. It includes Questions 51–140 (90 questions), four-option practice, topic filters, hints, answer feedback using the document's own answer key, missed-question revision, XP, streaks, timed mode, shuffle mode, and a playful arcade.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository named `pubad-panic-quiz`.
2. Upload all files from this folder into the repository root (`index.html`, `style.css`, `app.js`, `questions.js`, `README.md`, `.nojekyll`).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; branch `main`, folder `/(root)`, then Save.
5. Wait a minute or two. Your website URL will be `https://YOUR-GITHUB-USERNAME.github.io/pubad-panic-quiz/`.

No build tools, API keys, database, or installation are needed. Progress is saved in the same browser using local storage.

## Important source note
Question wording, options and keyed answers are taken from the uploaded file. Explanations explicitly identify the answer marked in that document; they are not represented as an independent fact-check of the source key.
